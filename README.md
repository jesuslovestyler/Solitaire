# Solitaire

Classic Klondike Solitaire — seven tableau piles, four foundations, stock and waste, with draw-1 or draw-3 play.

Drag-and-drop and tap-to-move controls, undo support, and a win celebration. Clean, calm card table that plays well on phones.

No scoreboard, no saved data — just the game, fresh every visit.

Built with Muse artifacts.
